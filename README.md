# Diari Football

축구 경기 시뮬레이션 웹앱입니다. 팀을 고르거나 만들고, 단판·합산·다전제 모드로 경기를 돌린 뒤 경기지·라인업·통계·이벤트 그래픽을 남깁니다.

## 기능

- **공식 국가대표** 공개 팀 + 커스텀 공개/비공개 팀
- 시즌 기록 기반 **능력치·OVR** 계산
- 감독 성격·전술·퍼스널 컬러
- 경기 모드: 단판, 2판 합산, 홈앤어웨이, 3판2선승, 5판3선승, 7전4선승
- 홈 어드밴티지 (모든 모드에서 선택 가능)
- 실시간 중계 로그 + 골/파울/오프사이드 **이벤트 리플레이**
- 경기는 브라우저에 저장, 백업 코드·동기화 코드로 다른 기기 이동 가능

## 로컬 실행

```bash
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:3456` 에서 뜹니다.

## 빌드

```bash
npm run build
npm start
```

GitHub Pages에 올리려면 정적 내보내기 대신 **Cursor Apps** 또는 Node 호스팅을 권장합니다. API(`/api/matches`)와 Postgres로 기기 간 동기화가 됩니다. DB가 없으면 로컬 저장 + 백업 코드만으로도 동작합니다.
